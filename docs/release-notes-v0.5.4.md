# WorkBuddy Shift 0.5.4

发布日期：2026-11-28

补丁版本，只改设置页交互与说明文案；数据格式与 0.5.3 一致，可直接升级。

## 修复

- **设置页目录落点**：点左侧目录后，平滑滚动偶尔停在上方卡片长高前算出的旧位置（19 次复验出现 1 次，短 89px），高亮随之落到上一节。现在跳转期间把高亮钉在目标节，滚动停稳后测量标题与落点线的差值，超过 2px 用非平滑滚动校正；落点确认后还会继续看守最多 10 秒，覆盖「数据加载比滚动更晚」导致的二次长高。`wheel` / `touchmove` / 滚动翻页键会立即取消校正并把控制权交还给你。高亮判定规则与深链行为都没有变。

## 文档

- **VS Code 插件限额口径**：设置页「限额监听」与 FAQ 此前写「暂不支持 / 能力缺口」，但从 0.5.0 起插件宿主日志已经作为一路来源在扫。现统一为「按本地日志识别（尽力而为）」，并写明三条边界：
  - 只读取本机日志，不向插件写入任何内容；
  - 插件没有实时上报通道，识别最多滞后一个扫描周期（约 5 分钟）；
  - 日志里没有记录时不会显示——看不到标记不代表没有被限流。
- README 的限额监听覆盖范围同步补上 VS Code 插件。

## 验证

- 前端单测 701 条通过；`typecheck`、`lint`、`build` 通过；13 项门禁通过。
- 设置页落点运行时复验：常规点击 19/19、加载后约 0.5 秒点击 6/6、延迟接口（900ms / 2.5s / 5s）6/6，落点都在 96±2；看守期内手动滚动 3/3 不被拉回。
- 桌面实机补测：0 账号时「导出」主按钮置灰，`导入备份` 保持可用（0 账号恢复入口）；按 Tab 可依次聚焦 `导入备份 → 更多导入方式 → 导出 → 更多导出方式` 四个独立控件。
